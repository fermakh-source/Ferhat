# Multilingual Animal Learning Video (Ages 0–5)

This repository now contains a complete implementation guide for producing a multilingual animal learning video for babies and children.

## 1) Scope Definition

- **Target age:** 0–5 years
- **Total length:** 3–5 minutes
- **Languages:** English, Spanish, Turkish
- **Learning goal:** Recognize animals by image, sound, and name in 3 languages

## 2) Video Structure (3–5 min)

1. **Intro song (15–20s)**
   - Friendly greeting
   - Explain: “Let’s learn animal names in 3 languages!”
2. **Animal section (8–12 animals, ~20–25s each)**
   - Show animal visual
   - Play animal sound
   - Display and speak name in English → Spanish → Turkish
3. **Recap section (30–45s)**
   - Faster review of all animals
   - Repeat names and sounds
4. **Outro (10–15s)**
   - Positive closing line and goodbye music

## 3) Child-Safe Script

### Intro Script

- “Hello, little learners!”
- “Let’s meet some animals!”
- “We will learn in English, Spanish, and Turkish.”
- “Are you ready? Let’s go!”

### Per-Animal Script Template

- “Look! It’s a **[Animal]**.”
- “In English: **[English Name]**.”
- “In Spanish: **[Spanish Name]**.”
- “In Turkish: **[Turkish Name]**.”
- “What sound does it make? **[Sound]**!”
- “Great job! Next animal!”

### Recap Script

- “Let’s remember our animals!”
- “**[Animal 1]** … **[Animal 2]** … **[Animal 3]** …”
- “You did amazing!”

## 4) Asset Preparation

### Visual Assets

- High-contrast, bright, child-friendly animal images or clips
- One clear hero visual per animal
- Simple background, minimal clutter

### Audio Assets

- Real animal sounds (clean, short, non-scary)
- Soft and cheerful background music (low volume under narration)
- Voiceover recordings in all 3 languages, clear and warm tone

### Minimum Asset List per Animal

- 1 image or short clip
- 1 animal sound effect
- 3 spoken labels (EN/ES/TR)
- 3 on-screen word labels (EN/ES/TR)

## 5) On-Screen Text Design Rules

- Large, rounded, readable font
- One word/label at a time
- Consistent text location (center-lower third)
- Color coding by language:
  - English: **Blue**
  - Spanish: **Green**
  - Turkish: **Orange**
- Keep each label visible long enough for early readers

## 6) Editing & Attention-Span Rules

- 5–10 seconds of focused content per beat
- Total per animal: ~20–25 seconds (visual + sound + 3 labels)
- Smooth transitions (simple fades/wipes)
- Frequent musical cues and gentle motion graphics
- Avoid overstimulation, harsh cuts, and loud spikes

## 7) Multilingual Flow (Fixed Order)

For every animal, keep this exact sequence:

1. Animal visual appears
2. Animal sound plays
3. English name (text + voice)
4. Spanish name (text + voice)
5. Turkish name (text + voice)
6. Positive reinforcement line

## 9) Quality Check Checklist

- [ ] Translation accuracy confirmed by native speakers
- [ ] Pronunciation reviewed for all voice lines
- [ ] Audio/text sync verified for each animal
- [ ] Background music level stays below narration
- [ ] No flashing or overstimulating visuals
- [ ] Mobile and TV playback tested
- [ ] All labels are legible and consistently placed
