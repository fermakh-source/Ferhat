# Ferhat

## Vidéo éducative : les animaux (Français / English / العربية)

Objectif : créer une courte vidéo pour bébé et enfants afin d’apprendre les animaux en 3 langues.

### Structure conseillée (2 à 3 minutes)
1. **Intro** : "Bonjour ! Hello! مرحباً!"
2. **Un animal par scène** (image + voix lente + texte à l’écran)
3. **Révision rapide** de tous les animaux
4. **Outro** : "Bravo ! Great job! أحسنتم!"

### Liste d’animaux trilingue
| Français | English | العربية |
|---|---|---|
| Chat | Cat | قطة |
| Chien | Dog | كلب |
| Oiseau | Bird | طائر |
| Poisson | Fish | سمكة |
| Lion | Lion | أسد |
| Éléphant | Elephant | فيل |
| Singe | Monkey | قرد |
| Lapin | Rabbit | أرنب |
| Vache | Cow | بقرة |
| Canard | Duck | بطة |

### Script type pour chaque scène
- "C’est un **chat**."
- "It is a **cat**."
- "هذه **قطة**."

### Conseils pour enfants
- Utiliser une voix douce et lente.
- Afficher un seul animal à la fois.
- Répéter chaque mot 2 fois.
- Ajouter une musique calme en fond.
